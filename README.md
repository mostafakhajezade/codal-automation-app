# نبض کدال (Codal Insight)

یک داشبورد سبک برای پیگیری اطلاعیه‌های [کدال](https://www.codal.ir)، بررسی رشد فروش ماهانه و مقایسه عملکرد سالانه شرکت‌ها.

## اجرا

این پروژه هیچ وابستگی npm ندارد و با Node.js 18 یا جدیدتر اجرا می‌شود:

```bash
npm start
```

سپس `http://localhost:3000` را باز کنید. سرور، درخواست اطلاعیه‌ها را سمت سرور به جست‌وجوی کدال ارسال می‌کند تا مشکل CORS در مرورگر وجود نداشته باشد. اگر سرویس کدال موقتاً در دسترس نباشد، رابط کاربری با داده‌های نمونه و یک پیام مشخص باقی می‌ماند.

## ساختار

* `server.mjs`: وب‌سرور بدون وابستگی و پراکسی API کدال.
* `public/`: رابط واکنش‌گرا و اسکریپت دریافت/نمایش اطلاعیه‌ها.
